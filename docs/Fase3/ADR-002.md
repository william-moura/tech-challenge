# 🏛️ ADR 002: Orquestrador Kubernetes K3s em AWS EC2

* **Status:** Aceito
* **Data:** 15 de Setembro de 2026
* **Autores:** Grupo SOAT - Software Architecture

---

## 1. Contexto
É necessário executar a aplicação principal em um ambiente de orquestração de containers com suporte a autoscaling, resiliência de pods e isolamento de dependências.

---

## 2. Decisão
Utilizar o **K3s** (distribuição Kubernetes leve certificada pela CNCF) sobre uma instância **AWS EC2 (Amazon Linux 2023)**.

---

## 3. Consequências
### Positivas:
* Menor consumo de CPU/Memória em comparação com distribuições padrão ou EKS, garantindo estabilidade no tipo de instância `t2.micro`.
* Implantação e bootstrap automatizados via scripts Shell executados pelo GitHub Actions (`appleboy/ssh-action`).
* Suporte nativo a objetos de Deployment, Service, ConfigMap, Secret e Ingress.

### Negativas:
* Necessidade de automação no script de CI/CD para reinstalação do K3s caso a instância EC2 seja recriada pelo Terraform.
